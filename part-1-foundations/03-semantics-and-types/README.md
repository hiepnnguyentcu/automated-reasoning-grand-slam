# Chapter 3: Semantics and Types

Part 1: Foundations.

## Objective

Give programming languages precise meaning so that claims about programs can be stated and proved.

## Proof of mastery

Prove type soundness for a small typed language by hand in a closed-book exam.

## Topics

| Topic | Objective |
|---|---|
| [Induction Principles](induction-principles/) | Prove properties using structural, rule and well-founded induction. |
| [Operational Semantics](operational-semantics/) | Write big-step and small-step semantics for a small language and prove them equivalent. |
| [Denotational Semantics](denotational-semantics/) | Define the meaning of programs with domains and fixed points and relate it to operational semantics. |
| [Axiomatic Semantics](axiomatic-semantics/) | Relate Hoare-style program logics to operational semantics through soundness. |
| [Lambda Calculus](lambda-calculus/) | Evaluate terms under the standard strategies and encode data and recursion. |
| [Type Systems](type-systems/) | Define type systems up to polymorphism and prove progress and preservation. |
