# Lambda Calculus

Part 1, Chapter 3: Semantics and Types.

## Objective

Evaluate terms under the standard strategies and encode data and recursion.

## Why this matters

The lambda calculus is the smallest language in which binding, substitution and higher-order functions can be studied. Those three issues recur in almost every reasoning tool: quantifier instantiation in [Chapter 6](../../../part-2-core-reasoning/06-first-order-proving/) is substitution, and the kernels of the proof assistants in [Chapter 12](../../../part-4-remaining-methods/12-proof-assistants/) are typed lambda calculi whose conversion check is the theory developed here. This topic is also the direct prerequisite of [Type Systems](../type-systems/), where evaluation strategy determines how soundness is stated. An applied scientist who has to get capture-avoiding substitution right in a verification tool will meet the pitfalls listed here.

## Lesson

### Syntax and binding

Terms are given by

$$M, N ::= x \mid \lambda x.\ M \mid M\ N.$$

Application associates to the left, so $M\ N\ L$ means $(M\ N)\ L$. The body of an abstraction extends as far to the right as possible, so $\lambda x.\ M\ N$ means $\lambda x.\ (M\ N)$. The abbreviation $\lambda x\,y.\ M$ means $\lambda x.\ \lambda y.\ M$.

Free variables are defined by $\mathrm{FV}(x) = \{x\}$, $\mathrm{FV}(\lambda x.\ M) = \mathrm{FV}(M) \setminus \{x\}$ and $\mathrm{FV}(M\ N) = \mathrm{FV}(M) \cup \mathrm{FV}(N)$. A term with no free variables is closed.

Capture-avoiding substitution $M[N/x]$ is defined by

$$x[N/x] = N, \qquad y[N/x] = y \ \ (y \ne x), \qquad (M_1\ M_2)[N/x] = M_1[N/x]\ M_2[N/x],$$

$$(\lambda x.\ M)[N/x] = \lambda x.\ M,$$

$$(\lambda y.\ M)[N/x] = \lambda y.\ M[N/x] \quad \text{if } y \ne x \text{ and } y \notin \mathrm{FV}(N),$$

$$(\lambda y.\ M)[N/x] = \lambda z.\ M[z/y][N/x] \quad \text{if } y \ne x \text{ and } y \in \mathrm{FV}(N), \text{ with } z \text{ fresh.}$$

The last clause exists because a free variable of $N$ must not become bound. Without renaming, $(\lambda y.\ x)[y/x]$ would yield $\lambda y.\ y$, turning a constant function into the identity.

Alpha-equivalence, written $=_\alpha$, is the congruence generated by $\lambda y.\ M =_\alpha \lambda z.\ M[z/y]$ for $z \notin \mathrm{FV}(M)$. Terms are identified up to $=_\alpha$. Under Barendregt's variable convention, bound variables are chosen different from all free variables in the current context, so the renaming clause can be left implicit in proofs. Implementations often use de Bruijn indices, which replace a bound variable by the number of binders between it and its binder, so that alpha-equivalent terms are syntactically equal.

### Reduction

The basic rule is beta reduction:

$$(\lambda x.\ M)\ N \to_\beta M[N/x].$$

A term of the form $(\lambda x.\ M)\ N$ is a redex. The relation $\to_\beta$ is the compatible closure of this rule: a redex may be contracted anywhere inside a term. The relation $\to_\beta^{\ast}$ is the reflexive transitive closure, and $=_\beta$ is the smallest equivalence containing $\to_\beta$. The eta rule, $\lambda x.\ M\ x \to_\eta M$ when $x \notin \mathrm{FV}(M)$, expresses extensionality, and it is a separate rule that is not part of $\to_\beta$.

A term with no redex is in normal form. A term is weakly normalizing if some reduction sequence reaches a normal form, and strongly normalizing if all reduction sequences are finite. Let $\Omega = (\lambda x.\ x\ x)\ (\lambda x.\ x\ x)$. It reduces only to itself, so it has no normal form. The term $(\lambda x\,y.\ x)\ (\lambda z.\ z)\ \Omega$ is weakly normalizing and not strongly normalizing.

### Confluence

Theorem 1 (Church–Rosser). If $M \to_\beta^{\ast} N_1$ and $M \to_\beta^{\ast} N_2$, then there is $L$ with $N_1 \to_\beta^{\ast} L$ and $N_2 \to_\beta^{\ast} L$.

The direct approach fails, because one-step reduction does not have the diamond property (Exercise 7). A step can duplicate a redex, so closing a diagram can take several steps. The Tait and Martin-Löf method defines a relation that contracts many redexes at once, and Takahashi's refinement below makes the proof short.

Definition. Parallel reduction $\Rightarrow$ is defined by the rules:

$$\frac{}{x \Rightarrow x} \qquad \frac{M \Rightarrow M'}{\lambda x.\ M \Rightarrow \lambda x.\ M'} \qquad \frac{M \Rightarrow M' \quad N \Rightarrow N'}{M\ N \Rightarrow M'\ N'} \qquad \frac{M \Rightarrow M' \quad N \Rightarrow N'}{(\lambda x.\ M)\ N \Rightarrow M'[N'/x]}$$

Lemma 2. The relation $\Rightarrow$ is reflexive, ${\to_\beta} \subseteq {\Rightarrow} \subseteq {\to_\beta^{\ast}}$, and hence the reflexive transitive closure of $\Rightarrow$ equals $\to_\beta^{\ast}$.

Proof. Reflexivity is by structural induction. The first inclusion is by rule induction on the compatible closure, using reflexivity for the untouched parts. The second is by rule induction on $\Rightarrow$: for the last rule, reduce inside $M$, then inside $N$, and then contract the redex. $\square$

Lemma 3 (substitution). If $M \Rightarrow M'$ and $N \Rightarrow N'$, then $M[N/x] \Rightarrow M'[N'/x]$.

Proof. Use rule induction on $M \Rightarrow M'$, with bound variables chosen different from $x$ and not free in $N$.

Case variable $x$: $N \Rightarrow N'$ is the assumption. Case variable $y \ne x$: $y \Rightarrow y$. The abstraction and application cases follow by the hypotheses and the same rule.

Case $(\lambda y.\ P)\ Q \Rightarrow P'[Q'/y]$. The hypotheses give $P[N/x] \Rightarrow P'[N'/x]$ and $Q[N/x] \Rightarrow Q'[N'/x]$. The last rule gives

$$(\lambda y.\ P[N/x])\ Q[N/x] \Rightarrow P'[N'/x]\bigl[Q'[N'/x]/y\bigr].$$

The right side equals $P'[Q'/y][N'/x]$ by the substitution lemma of Exercise 10, which applies since $y \ne x$ and $y \notin \mathrm{FV}(N')$. The side condition on $N'$ holds because parallel reduction does not introduce free variables. $\square$

Definition. The complete development $M^{\star}$ contracts all redexes visible in $M$:

$$x^{\star} = x, \qquad (\lambda x.\ M)^{\star} = \lambda x.\ M^{\star}, \qquad ((\lambda x.\ M)\ N)^{\star} = M^{\star}[N^{\star}/x],$$

$$(M\ N)^{\star} = M^{\star}\ N^{\star} \quad \text{if } M \text{ is not an abstraction.}$$

Lemma 4 (triangle). If $M \Rightarrow N$, then $N \Rightarrow M^{\star}$.

Proof. Use rule induction on $M \Rightarrow N$.

Case variable: $x \Rightarrow x = x^{\star}$. Case abstraction: immediate from the hypothesis.

Case application $M_1\ M_2 \Rightarrow M_1'\ M_2'$ with $M_1$ not an abstraction: the hypotheses give $M_1' \Rightarrow M_1^{\star}$ and $M_2' \Rightarrow M_2^{\star}$, and the application rule concludes.

Case application $(\lambda x.\ P)\ M_2 \Rightarrow M_1'\ M_2'$: inversion on $\lambda x.\ P \Rightarrow M_1'$ gives $M_1' = \lambda x.\ P'$ with $P \Rightarrow P'$. The hypotheses give $P' \Rightarrow P^{\star}$ and $M_2' \Rightarrow M_2^{\star}$. The redex rule gives $(\lambda x.\ P')\ M_2' \Rightarrow P^{\star}[M_2^{\star}/x]$, which is the complete development.

Case $(\lambda x.\ P)\ Q \Rightarrow P'[Q'/x]$: the hypotheses give $P' \Rightarrow P^{\star}$ and $Q' \Rightarrow Q^{\star}$. Lemma 3 gives $P'[Q'/x] \Rightarrow P^{\star}[Q^{\star}/x]$. $\square$

Proof of Theorem 1. Lemma 4 gives the diamond property of $\Rightarrow$: if $M \Rightarrow N_1$ and $M \Rightarrow N_2$, both reach $M^{\star}$ in one parallel step. A relation with the diamond property has a confluent reflexive transitive closure, by tiling a grid of diamonds whose sides are the two reduction sequences. By Lemma 2, that closure is $\to_\beta^{\ast}$. $\square$

Corollary 5. (a) If $M =_\beta N$, then $M$ and $N$ have a common reduct. (b) A term has at most one normal form up to $=_\alpha$. (c) If $M =_\beta N$ and $N$ is in normal form, then $M \to_\beta^{\ast} N$. (d) The theory $=_\beta$ is consistent: $\lambda x\,y.\ x \ne_\beta \lambda x\,y.\ y$, since these are distinct normal forms.

Exercise 11 asks for the proofs.

### Evaluation strategies

Confluence says that the choice of redex cannot produce two different normal forms. It does not say that each choice finds the normal form, and the choices have very different costs. A strategy fixes the choice. Two of the following strategies compute full normal forms, and two are weak strategies that model programming languages, stopping at an abstraction without looking inside.

| Strategy | Redex selected | Goes under an abstraction | Argument evaluated before the call |
|---|---|---|---|
| Normal order | It selects the leftmost outermost redex. | It goes under an abstraction. | It does not evaluate the argument first. |
| Applicative order | It selects the leftmost innermost redex. | It goes under an abstraction. | It evaluates the argument first. |
| Call-by-name | It selects the leftmost outermost redex outside any abstraction. | It does not go under an abstraction. | It does not evaluate the argument first. |
| Call-by-value | It selects the leftmost redex whose argument is a value, outside any abstraction. | It does not go under an abstraction. | It evaluates the argument first. |

The weak strategies are defined by small-step rules. Values are $V ::= x \mid \lambda x.\ M$. Variables count as values so that open examples can be evaluated, and for closed programs the values are abstractions.

Call-by-name:

$$\frac{}{(\lambda x.\ M)\ N \longrightarrow_{n} M[N/x]} \qquad \frac{M \longrightarrow_{n} M'}{M\ N \longrightarrow_{n} M'\ N}$$

Call-by-value:

$$\frac{}{(\lambda x.\ M)\ V \longrightarrow_{v} M[V/x]} \qquad \frac{M \longrightarrow_{v} M'}{M\ N \longrightarrow_{v} M'\ N} \qquad \frac{N \longrightarrow_{v} N'}{V\ N \longrightarrow_{v} V\ N'}$$

The corresponding big-step rules for closed terms are as follows. For call-by-name, $\lambda x.\ M \Downarrow_n \lambda x.\ M$, and from $M \Downarrow_n \lambda x.\ P$ and $P[N/x] \Downarrow_n W$ infer $M\ N \Downarrow_n W$. For call-by-value, $\lambda x.\ M \Downarrow_v \lambda x.\ M$, and from $M \Downarrow_v \lambda x.\ P$, $N \Downarrow_v V$ and $P[V/x] \Downarrow_v W$ infer $M\ N \Downarrow_v W$.

Both weak relations are deterministic, by rule induction as in [Operational Semantics](../operational-semantics/). A closed term that is not a value has a call-by-name step only if its head eventually exposes an abstraction, and this always holds in the pure closed calculus.

Theorem 6 (normalization, or standardization). If $M$ has a normal form, then normal-order reduction from $M$ reaches it.

This result goes back to Curry and Feys. Its proof uses the standardization theorem, which says that any reduction sequence can be rearranged so that redexes are contracted from left to right. The lesson does not prove it, and Barendregt's book gives a full treatment.

Normal order is complete in this sense, but it can be inefficient, since an argument used twice is evaluated twice. Call-by-value evaluates each argument once, including arguments that are never used, which may diverge. Call-by-need, which is call-by-name with sharing of evaluated arguments, was introduced to obtain the benefit of both. Plotkin's 1975 paper established the relation between the two weak strategies and their equational theories, and it also showed how to simulate each by the other through a program translation.

### Encoding data

In the pure calculus, data is represented by its behaviour under elimination. The notation $\lceil n \rceil$ is written $c_n$ below.

Booleans:

$$\mathsf{true} = \lambda t\,e.\ t, \qquad \mathsf{false} = \lambda t\,e.\ e, \qquad \mathsf{if} = \lambda p\,t\,e.\ p\ t\ e.$$

Pairs:

$$\mathsf{pair} = \lambda a\,b\,s.\ s\ a\ b, \qquad \mathsf{fst} = \lambda p.\ p\ \mathsf{true}, \qquad \mathsf{snd} = \lambda p.\ p\ \mathsf{false}.$$

Church numerals represent $n$ as $n$-fold iteration, where $f^{n}\ x$ means $f\ (f\ (\cdots (f\ x)))$ with $n$ applications:

$$c_n = \lambda f\,x.\ f^{n}\ x.$$

Arithmetic:

$$\mathsf{succ} = \lambda n\,f\,x.\ f\ (n\ f\ x), \qquad \mathsf{add} = \lambda m\,n\,f\,x.\ m\ f\ (n\ f\ x), \qquad \mathsf{mul} = \lambda m\,n\,f.\ m\ (n\ f),$$

$$\mathsf{exp} = \lambda m\,n.\ n\ m, \qquad \mathsf{iszero} = \lambda n.\ n\ (\lambda z.\ \mathsf{false})\ \mathsf{true}.$$

Predecessor is harder, since an iterator only goes up. Kleene's solution iterates on pairs: start at $\langle c_0, c_0\rangle$ and repeatedly map $\langle a, b\rangle$ to $\langle b, \mathsf{succ}\ b\rangle$. After $n \ge 1$ iterations the pair is $\langle c_{n-1}, c_n\rangle$.

$$\mathsf{ss} = \lambda p.\ \mathsf{pair}\ (\mathsf{snd}\ p)\ (\mathsf{succ}\ (\mathsf{snd}\ p)), \qquad \mathsf{pred} = \lambda n.\ \mathsf{fst}\ (n\ \mathsf{ss}\ (\mathsf{pair}\ c_0\ c_0)).$$

Lists can be encoded as their right fold:

$$\mathsf{nil} = \lambda c\,n.\ n, \qquad \mathsf{cons} = \lambda h\,t\,c\,n.\ c\ h\ (t\ c\ n).$$

The list with elements $a_1, a_2$ is, up to $=_\beta$, $\lambda c\,n.\ c\ a_1\ (c\ a_2\ n)$, and applying it to $\mathsf{add}$ and $c_0$ sums it. These encodings, together with the fixed points below, make every computable function on numerals definable, which is the content of the equivalence of $\lambda$-definability with Turing computability established by Kleene and Turing. Church used the calculus in 1936 to give an undecidable problem: whether a term has a normal form.

### Encoding recursion

A recursive definition asks for a solution of an equation $f = F\ f$. The calculus always has one.

Theorem 7 (fixed-point theorem). Let $Y = \lambda f.\ (\lambda x.\ f\ (x\ x))\ (\lambda x.\ f\ (x\ x))$. For every term $F$, $Y\ F =_\beta F\ (Y\ F)$.

Proof. Let $W = \lambda x.\ F\ (x\ x)$. Then $Y\ F \to_\beta W\ W \to_\beta F\ (W\ W)$, and $F\ (Y\ F) \to_\beta F\ (W\ W)$. Both have the common reduct $F\ (W\ W)$. $\square$

The term $Y\ F$ does not reduce to $F\ (Y\ F)$; they are only convertible (Exercise 8). Turing's combinator $\Theta = A\ A$, with $A = \lambda x\,f.\ f\ (x\ x\ f)$, does satisfy $\Theta\ F \to_\beta^{\ast} F\ (\Theta\ F)$.

Under call-by-value, $Y\ F$ diverges, since the argument $W\ W$ of $F$ is evaluated first and it unfolds forever. The call-by-value fixed-point combinator delays the self-application by eta-expanding it:

$$Z = \lambda f.\ (\lambda x.\ f\ (\lambda v.\ x\ x\ v))\ (\lambda x.\ f\ (\lambda v.\ x\ x\ v)).$$

Note the parallel with [Denotational Semantics](../denotational-semantics/). In the models described there, $Y$ denotes the least fixed-point operator, which explains why recursion is meaningful in the untyped calculus even though most terms have no normal form.

### What is left out

Pure lambda calculus has no way to detect a type error, because every term can be applied to every term. An expression such as $\mathsf{add}\ \mathsf{true}\ c_1$ reduces to a normal form with no meaning as data. The next topic restricts terms by types, which rules out such terms and, in the simply typed case, also rules out $\Omega$ and $Y$.

## Worked examples

### Worked Example 1: comparing strategies

Let $M = (\lambda x.\ x\ x)\ ((\lambda y.\ y)\ z)$. The redex $(\lambda y.\ y)\ z$ is written $I\ z$ below, with $I = \lambda y.\ y$.

```
Normal order: leftmost outermost, full normal form (3 steps)
  (\x. x x) (I z)
  (I z) (I z)
  z (I z)
  z z

Applicative order: leftmost innermost, full normal form (2 steps)
  (\x. x x) (I z)
  (\x. x x) z
  z z

Call-by-name: stops when the head is not an abstraction (2 steps)
  (\x. x x) (I z)
  (I z) (I z)
  z (I z)
  stop: no call-by-name rule applies, since z is a variable in head position

Call-by-value (2 steps)
  (\x. x x) (I z)
  (\x. x x) z
  z z
```

Call-by-name stops with an unevaluated redex in argument position. That is a weak head normal form. Normal order continues into the argument. Duplication is why normal order takes one more step than applicative order here.

Now let $M' = (\lambda x\,y.\ x)\ I\ \Omega$.

```
Normal order and call-by-name (2 steps)
  (\x y. x) I Omega
  (\y. I) Omega
  I

Applicative order and call-by-value: no result
  (\x y. x) I Omega
  (\y. I) Omega
  (\y. I) Omega           contracting Omega inside the argument
  ... forever
```

Discarding an argument is what lets call-by-name terminate here. The traces and step counts were checked with a scratch reducer.

### Worked Example 2: arithmetic on Church numerals

Normal-order trace of $\mathsf{add}\ c_1\ c_1$, with $c_1 = \lambda f\,x.\ f\ x$:

```
(\m n f x. m f (n f x)) c1 c1
(\n f x. c1 f (n f x)) c1
\f x. c1 f (c1 f x)
\f x. (\x. f x) (c1 f x)        contracting c1 f
\f x. f (c1 f x)
\f x. f ((\x. f x) x)           contracting c1 f
\f x. f (f x)                   this is c2
```

The trace has 6 steps, and it was checked with a scratch reducer.

Predecessor of $c_2$ can be computed at the level of $=_\beta$. Write $\langle a, b\rangle$ for $\mathsf{pair}\ a\ b$. First, $\mathsf{ss}\ \langle a, b\rangle =_\beta \mathsf{pair}\ (\mathsf{snd}\ \langle a, b\rangle)\ (\mathsf{succ}\ (\mathsf{snd}\ \langle a, b\rangle)) =_\beta \langle b, \mathsf{succ}\ b\rangle$, because $\mathsf{snd}\ \langle a, b\rangle \to_\beta \langle a, b\rangle\ \mathsf{false} \to_\beta^{\ast} \mathsf{false}\ a\ b \to_\beta^{\ast} b$. Then

```
pred c2 =β fst (c2 ss <c0,c0>)
        =β fst (ss (ss <c0,c0>))        unfolding c2
        =β fst (ss <c0, succ c0>)
        =β fst (ss <c0, c1>)            succ c0 =β c1
        =β fst <c1, succ c1>
        =β c1
```

### Worked Example 3: a recursive function with Y

Let

$$F = \lambda r\,n.\ \mathsf{iszero}\ n\ c_1\ (\mathsf{mul}\ n\ (r\ (\mathsf{pred}\ n))),$$

and let $R = Y\ F$. By Theorem 7, $R =_\beta F\ R$. We compute $R\ c_1$ under $=_\beta$.

```
R c1 =β F R c1
     =β iszero c1 c1 (mul c1 (R (pred c1)))     beta twice
     =β false c1 (mul c1 (R (pred c1)))         iszero c1 =β false
     =β mul c1 (R (pred c1))                    false a b =β b
     =β mul c1 (R c0)                           pred c1 =β c0
     =β mul c1 (F R c0)                         fixed-point equation
     =β mul c1 (iszero c0 c1 (mul c0 (R (pred c0))))
     =β mul c1 (true c1 (mul c0 (R (pred c0)))) iszero c0 =β true
     =β mul c1 c1                               true a b =β a
     =β c1
```

The recursive call inside the discarded branch at the base case is never needed, and this is why normal order terminates here. By Corollary 5(c), $R\ c_1 \to_\beta^{\ast} c_1$. A scratch reducer confirmed that $Y\ F\ c_k$ reduces to $c_{k!}$ under normal order for $k = 0, \dots, 4$, and that $Y\ F$ does not reach a value under call-by-value within 3000 steps. The analysis of that divergence is that $F$ receives its argument $W\ W$ only after evaluating it, and evaluating $W\ W$ produces $F\ (W\ W)$, which again evaluates $W\ W$.

## Common mistakes

- Substituting naively under a binder. The result $(\lambda y.\ x)[y/x] = \lambda y.\ y$ is wrong. The correct result is $\lambda z.\ y$.
- Misreading the conventions. The term $\lambda x.\ x\ y$ is $\lambda x.\ (x\ y)$, and $x\ y\ z$ is $(x\ y)\ z$. Correct by inserting parentheses before reducing.
- Reducing under an abstraction in a weak strategy. Under call-by-value, $\lambda x.\ I\ x$ is a value and it is finished.
- Believing that confluence implies termination. Confluence says that normal forms are unique when they exist. The term $\Omega$ has none.
- Believing that normal order is always the most efficient. It finds a normal form when one exists, and it may duplicate work, as in Worked Example 1.
- Confusing normal form, weak head normal form and value. The term $z\ (I\ z)$ is in weak head normal form and not in normal form. The term $\lambda x.\ I\ x$ is a value and not in normal form.
- Claiming that $Y\ F \to_\beta^{\ast} F\ (Y\ F)$. They are only convertible. Use $\Theta$ if a literal reduction is required.
- Using $Y$ under call-by-value. It diverges. Use $Z$ instead.
- Treating the encoded $\mathsf{if}$ as lazy under call-by-value. Both branches are arguments, so both are evaluated. Exercise 12 gives the fix.
- Assuming that $\mathsf{exp}\ m\ c_0 =_\beta c_1$. The term reduces to $\lambda x.\ x$, which equals $c_1$ only under eta.

### Exercise 1

Fully parenthesize $\lambda x.\ x\ y\ \lambda y.\ y\ x$, and compute its free variables. Decide whether $\lambda x.\ x\ y =_\alpha \lambda y.\ y\ x$ and whether $\lambda x.\ x\ y =_\alpha \lambda z.\ z\ y$.

<details><summary>Solution</summary>

The term is $\lambda x.\ ((x\ y)\ (\lambda y.\ (y\ x)))$. Its free variables are $\{y\}$: the $y$ inside $x\ y$ is free, the inner $y$ is bound, and each $x$ is bound by the outer abstraction.

The first pair is not alpha-equivalent. The bodies have the bound variable in different positions: in the first it is the operator, and in the second it is the operand, while the free variable $y$ of the first has no counterpart in the second, which is closed.

The second pair is alpha-equivalent, by renaming $x$ to $z$, since $z$ is not free in $x\ y$.

</details>

### Exercise 2

Compute $(\lambda x.\ y\ x)[x/y]$, $(\lambda y.\ y\ x)[y\ z/x]$ and $(\lambda x.\ x)[z/x]$.

<details><summary>Solution</summary>

$(\lambda x.\ y\ x)[x/y] = \lambda x'.\ x\ x'$. The binder must be renamed, because the free $x$ being substituted would otherwise be captured.

$(\lambda y.\ y\ x)[y\ z/x] = \lambda y'.\ y'\ (y\ z)$. The renaming is needed because $y$ is free in $y\ z$.

$(\lambda x.\ x)[z/x] = \lambda x.\ x$. There is no free $x$ in the term, so nothing changes.

The first two were checked with a scratch implementation of substitution.

</details>

### Exercise 3

Let $I = \lambda w.\ w$ and $M = (\lambda y.\ \lambda x.\ y\ x)\ (I\ I)$. Give the reduction under each of the four strategies, and identify where each stops.

<details><summary>Solution</summary>

```
Normal order (3 steps)
  (\y. \x. y x) (I I)
  \x. (I I) x
  \x. I x
  \x. x

Applicative order (3 steps)
  (\y. \x. y x) (I I)
  (\y. \x. y x) I
  \x. I x
  \x. x

Call-by-name (1 step)
  (\y. \x. y x) (I I)

Call-by-value (2 steps)
  (\y. \x. y x) (I I)
  (\y. \x. y x) I
  \x. I x                     stop: this is an abstraction
```

The two full strategies agree with one another, as Corollary 5(b) requires. Each weak result is $\beta$-convertible to the normal form.

### Exercise 4

Define $\mathsf{not}$, $\mathsf{and}$ and $\mathsf{or}$ on encoded Booleans, and verify their truth tables.

<details><summary>Solution</summary>

Take $\mathsf{not} = \lambda p.\ p\ \mathsf{false}\ \mathsf{true}$, $\mathsf{and} = \lambda p\,q.\ p\ q\ \mathsf{false}$ and $\mathsf{or} = \lambda p\,q.\ p\ \mathsf{true}\ q$.

Use $\mathsf{true}\ a\ b \to_\beta^{\ast} a$ and $\mathsf{false}\ a\ b \to_\beta^{\ast} b$.

$\mathsf{not}\ \mathsf{true} \to_\beta \mathsf{true}\ \mathsf{false}\ \mathsf{true} \to_\beta^{\ast} \mathsf{false}$, and $\mathsf{not}\ \mathsf{false} \to_\beta \mathsf{false}\ \mathsf{false}\ \mathsf{true} \to_\beta^{\ast} \mathsf{true}$.

$\mathsf{and}\ \mathsf{true}\ q \to_\beta^{\ast} \mathsf{true}\ q\ \mathsf{false} \to_\beta^{\ast} q$, and $\mathsf{and}\ \mathsf{false}\ q \to_\beta^{\ast} \mathsf{false}\ q\ \mathsf{false} \to_\beta^{\ast} \mathsf{false}$. So all four rows are correct.

$\mathsf{or}\ \mathsf{true}\ q \to_\beta^{\ast} \mathsf{true}\ \mathsf{true}\ q \to_\beta^{\ast} \mathsf{true}$, and $\mathsf{or}\ \mathsf{false}\ q \to_\beta^{\ast} \mathsf{false}\ \mathsf{true}\ q \to_\beta^{\ast} q$. So all four rows are correct.

</details>

### Exercise 5

Prove that for $n \ge 1$ and $m \ge 0$, $c_n\ c_m =_\beta c_{m^n}$. Determine what $c_0\ c_m$ reduces to.

<details><summary>Solution</summary>

We have $c_n\ c_m \to_\beta \lambda x.\ c_m^{\,n}\ x$, where $c_m^{\,n}\ x$ means $n$ applications of $c_m$ to $x$.

Claim: for $n \ge 1$, $c_m^{\,n}\ x =_\beta \lambda y.\ x^{m^n}\ y$. Use induction on $n$.

For $n = 1$, $c_m\ x \to_\beta^{\ast} \lambda y.\ x^{m}\ y$ by the definition of $c_m$.

For the step, using the hypothesis,

$$c_m\ (c_m^{\,n}\ x) =_\beta c_m\ (\lambda y.\ x^{m^n}\ y) \to_\beta \lambda y.\ (\lambda y'.\ x^{m^n}\ y')^{m}\ y.$$

Each application of $\lambda y'.\ x^{m^n}\ y'$ to a term $T$ yields $x^{m^n}\ T$. So $m$ applications yield $x^{m \cdot m^n}\ y = x^{m^{n+1}}\ y$.

So $c_n\ c_m =_\beta \lambda x\,y.\ x^{m^n}\ y = c_{m^n}$.

For $n = 0$, $c_0\ c_m \to_\beta \lambda x.\ x$. This is a normal form different from $c_1 = \lambda f\,x.\ f\ x$, so by Corollary 5(d)'s argument they are not $\beta$-equal. They are $\eta$-equal, since $\lambda f.\ \lambda x.\ f\ x \to_\eta \lambda f.\ f$.

A scratch reducer confirmed the claim for $n = 1, 2, 3$ and $m = 0, \dots, 3$.

</details>

### Exercise 6

Prove that $\mathsf{pred}\ c_0 =_\beta c_0$ and $\mathsf{pred}\ c_{n+1} =_\beta c_n$.

<details><summary>Solution</summary>

Write $\langle a, b\rangle$ for $\mathsf{pair}\ a\ b$, and let $Z_0 = \langle c_0, c_0\rangle$. By the calculation in Worked Example 2, $\mathsf{ss}\ \langle a, b\rangle =_\beta \langle b, \mathsf{succ}\ b\rangle$. Also $\mathsf{succ}\ c_k =_\beta c_{k+1}$, because $\mathsf{succ}\ c_k \to_\beta \lambda f\,x.\ f\ (c_k\ f\ x) \to_\beta^{\ast} \lambda f\,x.\ f\ (f^{k}\ x)$.

Claim: $c_{n+1}\ \mathsf{ss}\ Z_0 =_\beta \langle c_n, c_{n+1}\rangle$. For $n = 0$, $c_1\ \mathsf{ss}\ Z_0 =_\beta \mathsf{ss}\ Z_0 =_\beta \langle c_0, c_1\rangle$. For the step, $c_{n+2}\ \mathsf{ss}\ Z_0 =_\beta \mathsf{ss}\ (c_{n+1}\ \mathsf{ss}\ Z_0)$, because $f^{n+2}\ x = f\ (f^{n+1}\ x)$. By the hypothesis, this equals $\mathsf{ss}\ \langle c_n, c_{n+1}\rangle =_\beta \langle c_{n+1}, c_{n+2}\rangle$.

Then $\mathsf{pred}\ c_{n+1} =_\beta \mathsf{fst}\ \langle c_n, c_{n+1}\rangle =_\beta c_n$. And $\mathsf{pred}\ c_0 =_\beta \mathsf{fst}\ (c_0\ \mathsf{ss}\ Z_0) =_\beta \mathsf{fst}\ Z_0 =_\beta c_0$.

</details>

### Exercise 7

Show that $\to_\beta$ does not have the diamond property, by using $M = (\lambda x.\ x\ x)\ (I\ z)$.

<details><summary>Solution</summary>

$M$ has two one-step reducts:

$$N_1 = (I\ z)\ (I\ z), \qquad N_2 = (\lambda x.\ x\ x)\ z.$$

The one-step reducts of $N_2$ are just $z\ z$. The one-step reducts of $N_1$ are $z\ (I\ z)$ and $(I\ z)\ z$. These do not include $z\ z$, so no single term is one step from both. Two steps from $N_1$ are needed to reach $z\ z$. Parallel reduction closes this: $N_1 \Rightarrow z\ z$ in one step.

</details>

### Exercise 8

Prove that $\Theta\ F \to_\beta^{\ast} F\ (\Theta\ F)$. Then show that, for a variable $f$, $Y\ f$ does not reduce to $f\ (Y\ f)$.

<details><summary>Solution</summary>

With $A = \lambda x\,g.\ g\ (x\ x\ g)$ and $\Theta = A\ A$: $A\ A\ F \to_\beta (\lambda g.\ g\ (A\ A\ g))\ F \to_\beta F\ (A\ A\ F) = F\ (\Theta\ F)$.

For the second claim, let $W = \lambda x.\ f\ (x\ x)$. A reduct of $Y\ f$ that has the variable $f$ at its head requires the outer redex $Y\ f$ to have been contracted, and the reducts of $W\ W$ are exactly the terms $f^{k}\ (W\ W)$ for $k \ge 0$, because $W\ W$ has a single redex and each contraction exposes one more $f$. To reach $f\ (Y\ f)$, we would need $f^{k-1}\ (W\ W) = Y\ f$ for some $k \ge 1$. This is impossible: the term $Y\ f$ is an application whose operator is an abstraction binding $f$ and whose operand is the variable $f$, whereas $f^{k-1}\ (W\ W)$ has operator $f$ or has operand $W$. So $f\ (Y\ f)$ is not a reduct of $Y\ f$. Both reduce to $f\ (W\ W)$, so they are convertible.

</details>

### Exercise 9

Let $U = \lambda x.\ F\ (\lambda v.\ x\ x\ v)$, so that $Z\ F \longrightarrow_v U\ U$ when $F$ is a value. Show that $Z\ F \longrightarrow_{v}^{\ast} F\ (\lambda v.\ U\ U\ v)$, and that for a value $V$, $(\lambda v.\ U\ U\ v)\ V \longrightarrow_v^{\ast} F\ (\lambda v.\ U\ U\ v)\ V$. Explain why this avoids the divergence of $Y$.

<details><summary>Solution</summary>

$Z\ F \longrightarrow_v U\ U$, since $F$ is a value. Then $U\ U \longrightarrow_v F\ (\lambda v.\ U\ U\ v)$, since $U$ is a value.

For a value $V$, $(\lambda v.\ U\ U\ v)\ V \longrightarrow_v U\ U\ V$, by the redex rule. The left-operator rule then gives $U\ U\ V \longrightarrow_v F\ (\lambda v.\ U\ U\ v)\ V$.

The argument $\lambda v.\ U\ U\ v$ passed to $F$ is an abstraction, hence a value, so evaluation stops at it. The self-application $U\ U$ runs only when the recursive function is called. With $Y$, the argument $W\ W$ is not a value, and it must be evaluated before $F$ is called, which repeats forever.

</details>

### Exercise 10

Prove the substitution lemma: if $x \ne y$ and $x \notin \mathrm{FV}(L)$, then $M[N/x][L/y] = M[L/y]\bigl[N[L/y]/x\bigr]$.

<details><summary>Solution</summary>

Use structural induction on $M$. By the variable convention, bound variables in $M$ are different from $x$ and $y$ and not free in $N$ or $L$.

Case $M = x$. The left side is $N[L/y]$. The right side is $x[L/y][N[L/y]/x] = x[N[L/y]/x] = N[L/y]$, since $x \ne y$.

Case $M = y$. The left side is $y[N/x][L/y] = y[L/y] = L$. The right side is $L[N[L/y]/x] = L$, since $x \notin \mathrm{FV}(L)$.

Case $M = z$ with $z \ne x, y$. Both sides are $z$.

Case $M = \lambda z.\ P$. Both substitutions pass under the binder, and the hypothesis for $P$ gives the equality of bodies.

Case $M = P\ Q$. Substitution distributes over application, and the hypotheses for $P$ and $Q$ conclude.

</details>

### Exercise 11

Prove Corollary 5.

<details><summary>Solution</summary>

(a) Use induction on the generation of $=_\beta$, the equivalence closure of $\to_\beta$. A reflexive case has common reduct $M$. If $M \to_\beta N$, then $N$ is a common reduct. Symmetry swaps the two reduction sequences. For transitivity, suppose $M$ and $N$ have common reduct $L_1$, and $N$ and $P$ have common reduct $L_2$. Theorem 1 applied to $N$ gives $L$ with $L_1 \to_\beta^{\ast} L$ and $L_2 \to_\beta^{\ast} L$, which is a common reduct of $M$ and $P$.

(b) If $M$ reduces to normal forms $N_1$ and $N_2$, Theorem 1 gives a common reduct $L$. A normal form has no redex, so its only reduct is itself. So $N_1 = L = N_2$ up to $=_\alpha$.

(c) By (a), $M$ and $N$ have a common reduct $L$. Since $N$ is normal, $L = N$. So $M \to_\beta^{\ast} N$.

(d) The two terms are distinct normal forms. If they were convertible, (a) would give a common reduct, and normality would make them equal, which is false.

</details>

### Exercise 12

Show that, under call-by-value, $\mathsf{if}\ \mathsf{true}\ I\ \Omega$ diverges. Design a thunked conditional, and trace it.

<details><summary>Solution</summary>

Under call-by-value, an application with a value operator requires its argument to be evaluated. The term parses as $((\mathsf{if}\ \mathsf{true})\ I)\ \Omega$. The operator reduces, $\mathsf{if}\ \mathsf{true}\ I \longrightarrow_v^{\ast} \lambda e.\ \mathsf{true}\ I\ e$, which is a value. Then the argument $\Omega$ must be evaluated, and it reduces to itself forever.

Thunked conditional. Wrap each branch in an abstraction, with a variable $d$ not free in the branches, and apply the selected thunk:

$$\mathsf{ifv}\ p\ a\ b := p\ (\lambda d.\ a)\ (\lambda d.\ b)\ I.$$

Trace with $p = \mathsf{true}$, $a = I$, and $b = \Omega$:

```
(\t e. t) (\d. I) (\d. Omega) I
(\e. \d. I) (\d. Omega) I           the argument \d. I is a value
(\d. I) I                           the argument \d. Omega is a value
I
```

The thunk $\lambda d.\ \Omega$ is a value, so $\Omega$ is never evaluated. This is the pattern that Exercise 9's recursion requires for its base case. A scratch reducer ran a recursive factorial on $c_2$ under call-by-value, with $Z$ and thunks, to completion.

</details>

### Exercise 13

Using the list encoding, compute the sum of the list with elements $c_1, c_2$ at the level of $=_\beta$. Define the length of a list.

<details><summary>Solution</summary>

Let $\ell = \mathsf{cons}\ c_1\ (\mathsf{cons}\ c_2\ \mathsf{nil})$. First, $\mathsf{cons}\ h\ t =_\beta \lambda c\,n.\ c\ h\ (t\ c\ n)$. So $\mathsf{cons}\ c_2\ \mathsf{nil} =_\beta \lambda c\,n.\ c\ c_2\ (\mathsf{nil}\ c\ n) =_\beta \lambda c\,n.\ c\ c_2\ n$. Then $\ell =_\beta \lambda c\,n.\ c\ c_1\ (c\ c_2\ n)$.

Therefore $\ell\ \mathsf{add}\ c_0 =_\beta \mathsf{add}\ c_1\ (\mathsf{add}\ c_2\ c_0) =_\beta \mathsf{add}\ c_1\ c_2 =_\beta c_3$.

Length: $\mathsf{length} = \lambda l.\ l\ (\lambda h\,r.\ \mathsf{succ}\ r)\ c_0$. On $\ell$ it gives $\mathsf{succ}\ (\mathsf{succ}\ c_0) =_\beta c_2$.

A scratch reducer confirmed sum and length on a three-element list.

</details>
