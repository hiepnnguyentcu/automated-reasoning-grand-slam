# Chapter 12: Proof Assistants

Part 4: Remaining Methods.

## Objective

Write machine-checked proofs and verified programs in Lean, Rocq, Isabelle and Dafny.

## Proof of mastery

Mechanize a correctness proof about part of your own solver.

## Topics

| Topic | Objective |
|---|---|
| [Type Theory](type-theory/) | Explain the propositions-as-types correspondence, dependent types and inductive families. |
| [Lean](lean/) | Prove program and mathematical properties in Lean 4 using tactics and automation. |
| [Rocq](rocq/) | Complete the Logical Foundations and Programming Language Foundations volumes in Rocq. |
| [Isabelle](isabelle/) | Formalize a language semantics and its proofs in Isabelle/HOL. |
| [Dafny](dafny/) | Verify imperative programs and data structures in Dafny and diagnose failed proofs. |
| [Rust Verification](rust-verification/) | Verify Rust code with Verus and compare the approach with Dafny. |
| [Verified Systems](verified-systems/) | Explain how CompCert and seL4 were verified and what their proofs assume. |
| [Mechanizing Your Solver](mechanizing-your-solver/) | Prove a core part of your SAT solver correct in a proof assistant. |
