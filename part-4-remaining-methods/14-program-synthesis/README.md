# Chapter 14: Program Synthesis

Part 4: Remaining Methods.

## Objective

Generate programs from specifications using search, solvers and learned guidance.

## Proof of mastery

Build a small synthesizer and evaluate it on SyGuS benchmarks.

## Topics

| Topic | Objective |
|---|---|
| [CEGIS and Sketching](cegis-and-sketching/) | Implement counterexample-guided inductive synthesis for programs with holes. |
| [Enumerative Search](enumerative-search/) | Implement bottom-up enumeration with pruning by observational equivalence. |
| [Syntax-Guided Synthesis](syntax-guided-synthesis/) | Express problems in the SyGuS format and explain how leading solvers approach them. |
| [Solver-Aided Programming](solver-aided-programming/) | Build a verifier and synthesizer for a small language using Rosette. |
| [Deductive and Type-Directed Synthesis](deductive-and-type-directed-synthesis/) | Derive programs from proofs and refinement types. |
| [Programming by Example](programming-by-example/) | Explain version space algebras and learned guidance for synthesis from examples. |
