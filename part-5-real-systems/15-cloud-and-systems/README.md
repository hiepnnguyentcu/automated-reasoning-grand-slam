# Chapter 15: Cloud and Systems

Part 5: Real Systems.

## Objective

Verify real distributed, authorization and Rust systems using the methods AWS applies in practice.

## Proof of mastery

Have verification contributions merged into a real open source project.

## Topics

| Topic | Objective |
|---|---|
| [Formal Methods at AWS](formal-methods-at-aws/) | Explain where and why AWS applies formal methods and what limits their adoption. |
| [Distributed Protocols](distributed-protocols/) | Specify and model-check a consensus or replication protocol in TLA+ and P. |
| [Access Policy Reasoning](access-policy-reasoning/) | Encode access policies in SMT and explain how Zelkova answers policy questions. |
| [Authorization Languages](authorization-languages/) | Explain how Cedar was designed for analysis and verified alongside its implementation. |
| [Rust Verification in Practice](rust-verification-in-practice/) | Write Kani proofs for real Rust code and explain their bounds and assumptions. |
| [Lightweight Formal Methods](lightweight-formal-methods/) | Apply executable specifications and property-based checking to a storage-style system. |
| [Open Source Contribution](open-source-contribution/) | Land reviewed verification contributions in one project and become a known contributor there. |

## Main materials

- Newcombe et al., How Amazon Web Services Uses Formal Methods, CACM 2015.
- Cook, Formal Reasoning About the Security of Amazon Web Services, CAV 2018.
- Rungta, A Billion SMT Queries a Day, CAV 2022.
