# Part 5: Real Systems

## Objective

Apply formal methods to real cloud, systems and cryptographic software and leave public evidence of that work.

Proof in this part is work accepted by real projects wherever possible.

## Chapters

| # | Chapter | Objective | Proof of mastery |
|--:|---|---|---|
| 15 | [Cloud and Systems](15-cloud-and-systems/) | Verify real distributed, authorization and Rust systems using the methods AWS applies in practice. | Have verification contributions merged into a real open source project. |
| 16 | [Cryptographic Assurance](16-cryptographic-assurance/) | Prove functional correctness and side-channel properties of real cryptographic code. | Verify a real implementation of a cryptographic primitive against a formal specification. |
