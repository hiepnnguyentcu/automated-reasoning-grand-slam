# Chapter 18: Guarantees for LLM Output

Part 6: AI and Reasoning.

## Objective

State and enforce precise formal guarantees about what LLMs produce, including code and specifications.

## Proof of mastery

Publish a peer-reviewed paper from your LLM and formal specification research.

## Topics

| Topic | Objective |
|---|---|
| [Autoformalization](autoformalization/) | Translate natural language into logic and measure whether the meaning was preserved. |
| [Guarantees for Natural Language Answers](guarantees-for-natural-language-answers/) | Explain what Automated Reasoning checks in Amazon Bedrock prove and what they assume. |
| [Specification Synthesis](specification-synthesis/) | Generate formal specifications with LLMs, including in Alloy, and repair those with the wrong meaning. |
| [Intent Formalization](intent-formalization/) | Validate generated specifications against user intent using tests and interaction. |
| [Verified Code Generation](verified-code-generation/) | Generate code with machine-checked proofs in Dafny and Verus. |
| [Measuring Semantic Correctness](measuring-semantic-correctness/) | Design metrics and benchmarks that detect specifications that compile but mean the wrong thing. |
| [Research Paper](research-paper/) | Turn your current research into a submitted paper with a named venue and deadline. |
